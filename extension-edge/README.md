# Gemini Cookie Auto-Sync (Microsoft Edge)

Ekstensi Microsoft Edge untuk menyinkronkan cookie Google Gemini langsung ke server lokal `gemini-web2api-go` dalam 1 klik.

## Cara Pemasangan di Microsoft Edge

1. Buka Microsoft Edge.
2. Masuk ke halaman ekstensi:
   `edge://extensions/`
3. Di panel sebelah kiri, aktifkan toggle **Mode Pengembang** (*Developer mode*).
4. Klik tombol **Muat yang belum dibongkar** (*Load unpacked*).
5. Pilih folder:
   `G:\api\extension-edge`
6. Ekstensi **Gemini Cookie Auto-Sync (Microsoft Edge)** akan muncul di toolbar Edge.

## Cara Menggunakan

1. Buka tab Gemini Anda di Edge:
   `https://gemini.google.com/app`
   *(Pastikan Anda sudah login dan model **4 Neon** aktif)*
2. Klik ikon ekstensi di toolbar Edge.
3. Klik tombol **⚡ Sync Cookie ke Web2API**.
4. Status akan langsung terverifikasi hijau:
   `✅ SUKSES! 登录态有效`
5. Model `gemini-4-neon` langsung siap dipakai di API lokal!
